# 5S Annotator

**Professional mobile photo annotation tool for 5S lean manufacturing documentation.**

🚀 **[Launch App](https://zackc150.github.io/5S-Annotator/index.html)** · 📖 **[Learn More](https://zackc150.github.io/5S-Annotator/landing.html)**

-----

## Features

**Drawing (12 tools)**

- Hazard tape (6 stripe combos) · Solid color tape · Line · Zone · Circle · Curve · Rectangle · Arrow · Label · Callout · Freehand · Shadow board

**Measurements**

- Calibrate scale by tapping two known points
- Every annotation shows real dimensions (ft, in, m, cm)
- CAD-style dimension lines with arrows on export

**Edit Mode**

- Move · Resize · Rotate · Duplicate · Lock · Z-order
- Copy style across annotations
- Add notes to any annotation
- Opacity control per annotation

**Export**

- Save annotated photo to camera roll (iPhone) or download (Mac)
- Generate PDF-ready audit report with dimensions and notes
- Export 5S audit score sheet
- Save/restore full sessions as .5ss files

**Smart drawing**

- Snap to endpoints and midpoints
- Angle lock (0°/45°/90°)
- Auto-close shapes
- Live preview for every tool
- CAD-style centerline on tape annotations

**Other**

- AI shadow board detection
- Fullscreen mode
- Keyboard shortcuts (Mac)
- Works offline as PWA
- HEIC photo support

## Install on iPhone

1. Open [the app](https://zackc150.github.io/5S-Annotator/index.html) in Safari
1. Tap Share → Add to Home Screen
1. Opens fullscreen, works offline
