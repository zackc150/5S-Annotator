# 5S Annotator

**Free mobile-first photo annotation tool for 5S lean manufacturing documentation.**

🚀 **[Launch App](https://zackc150.github.io/5S-Annotator/index.html)** · 📖 **[Learn More](https://zackc150.github.io/5S-Annotator/landing.html)**

-----

## Features

- **Hazard tape lines** — black/yellow, red/white, and all 5S standard stripe patterns with clean mitered corners
- **Zone marking** — multi-point filled zones in all 5S colors
- **Shadow boards** — manual trace or AI-powered tool detection
- **Move · Resize · Rotate** — full annotation editing with handles
- **5S Audit scoring** — rate each S 1–5, export audit report
- **PDF report generator** — annotated photo + action table + audit scores
- **Auto legend overlay** — color key exports with your photo
- **PWA** — installs on iPhone home screen, works offline

## 5S Color Standard

|Color                 |Use                                          |
|----------------------|---------------------------------------------|
|🟡 Yellow              |Aisles · Traffic lanes · Work cell boundaries|
|⬜ White               |Equipment · Workstations · Carts             |
|🟢 Green               |Finished goods · Safe areas · First aid      |
|🔴 Red                 |Defects · Scrap · Quarantine                 |
|🔵 Blue                |Raw materials · Work in process              |
|🟠 Orange              |Inspection · Items awaiting decision         |
|⬛🟡 Black/Yellow stripe|Hazard · Physical danger zones               |
|🔴⬜ Red/White stripe   |Fire equipment · Emergency access            |

## Install on iPhone

1. Open [the app](https://zackc150.github.io/5S-Annotator/index.html) in Safari
1. Tap Share → Add to Home Screen
